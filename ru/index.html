Исправьте текст, набранный не в той раскладке, одной клавишей

Layout Fixer — небольшая программа для Windows 10 и 11, которая живёт в трее. Забыли переключить раскладку и вместо привет получили ghbdtn? Выделите текст и нажмите Ctrl+Shift+L — он сразу заменится на правильный прямо на месте. Работает в обе стороны (EN → RU и RU → EN), направление определяется автоматически.

1,99 $ (США), разовая покупка в Microsoft Store; в других странах цена может отличаться. Версия 1.1. Windows 10 (1809 и новее) и Windows 11, x64 и ARM64.

Как это работает

  1. Выделите «абракадабру» почти в любой программе: в браузере, Word, почте, мессенджере, Блокноте.
  2. Нажмите Ctrl+Shift+L (сочетание можно изменить).
  3. Программа определит, в какой раскладке набран текст, заменит каждый символ на тот, что находится на той же клавише в другой раскладке, и вставит результат вместо выделения. Прежнее содержимое буфера обмена восстанавливается.

Поддерживаемые раскладки

Стандартные раскладки Windows: английская (США), русская, украинская, арабская (101), персидская и персидская (стандартная), курдская (сорани), иврит и иврит (стандартная), греческая, турецкая Q. Конвертировать можно между любыми двумя из них (например, русская ⇄ украинская). По умолчанию пара берётся из раскладок, установленных в вашей Windows.

В Microsoft Store приложение называется «Layout Fixer – Arabic English» (ID 9N32C01ML8D1), но, несмотря на название, поддерживает все раскладки, перечисленные ниже.

Возможности

  • Одна горячая клавиша исправляет выделенный текст на месте или, по желанию, только текст в буфере обмена
  • Автоматическое определение направления или принудительное направление
  • Любая пара поддерживаемых раскладок; по умолчанию — установленные в Windows
  • По желанию переключает раскладку клавиатуры на правильную после исправления
  • Буква ё и знак № обрабатываются корректно; цифры остаются как есть
  • Работает из трея, может запускаться вместе с Windows
  • Интерфейс на 15 языках, включая русский и украинский
  • Полностью офлайн: без интернета, телеметрии, рекламы и учётных записей

Ограничения

  • Только для Windows (версий для macOS, Linux, Android и iOS нет).
  • Только перечисленные раскладки: например, «русская (фонетическая)» и «русская (машинопись)» не поддерживаются.
  • Символы, набираемые через AltGr, не преобразуются.
  • Программа не следит за набором и не переключает раскладку сама «на лету» — исправление происходит только по горячей клавише.
  • Это не переводчик: ghbdtn превращается в «привет», а не в «hello».

Частые вопросы

Как исправить текст, набранный не в той раскладке, в Windows?

Установите Layout Fixer из Microsoft Store, выделите текст, набранный не в той раскладке, и нажмите Ctrl+Shift+L. Выделение заменится текстом в правильной раскладке. Встроенной команды для этого в Windows нет — без такой программы текст приходится стирать и набирать заново.

Как перевести «ghbdtn» в «привет»?

«ghbdtn» — это слово «привет», набранное при включённой английской раскладке. Выделите его и нажмите Ctrl+Shift+L — получится «привет». Целые фразы тоже работают: «Ghbdtn? vbh» станет «Привет, мир».

А наоборот — «руддщ» в «hello»?

Да. Направление определяется автоматически: «руддщ цщкдв» превратится в «hello world». При желании направление можно задать вручную в настройках.

Чем Layout Fixer отличается от Punto Switcher?

Layout Fixer не отслеживает ввод и не переключает раскладку автоматически во время набора. Он срабатывает только тогда, когда вы сами нажимаете горячую клавишу на выделенном тексте, и работает полностью офлайн.

Это переводчик?

Нет. Каждый символ заменяется на тот, что находится на той же физической клавише в другой раскладке, — то есть на то, что вы набрали бы при правильной раскладке. Смысл не переводится.

Какие раскладки поддерживаются?

Английская (США), русская, украинская, арабская (101), персидская, персидская (стандартная), курдская (сорани), иврит, иврит (стандартная), греческая и турецкая Q — между любыми двумя из них. Интерфейс программы доступен на 15 языках.

В каких программах это работает?

Почти во всех программах Windows, где можно выделить текст и использовать Ctrl+C / Ctrl+V: в браузерах, Microsoft Office, почтовых клиентах и мессенджерах. Если программа запрещает копирование, можно включить режим исправления только буфера обмена.

Отправляет ли программа мой текст куда-нибудь?

Нет. Layout Fixer работает полностью офлайн, не содержит телеметрии и аналитики и не сохраняет преобразованный текст.

Сколько стоит и есть ли версия для Mac или телефона?

1,99 $ в США (разовая покупка в Microsoft Store, цена зависит от страны). Программа доступна только для Windows 10 (1809 и новее) и Windows 11.
