Fix text typed in the wrong keyboard layout — with one hotkey

Layout Fixer is a small Windows 10/11 tray app. If you forgot to switch the keyboard language and typed ghbdtn instead of привет, or hgsghl ugd;l instead of السلام عليكم, select the text and press Ctrl+Shift+L. The text is replaced in place with what you meant to type. It works in both directions and detects the direction automatically.

US$1.99 with a <b>7-day free trial</b> in the Microsoft Store (local prices may vary). Version 1.2 · <b>62 keyboard layouts</b>. Windows 10 (1809 or later) and Windows 11, x64 and ARM64.

How it works

  1. Select the garbled text in almost any app — a browser, Word, an email or chat window, Notepad.
  2. Press Ctrl+Shift+L (you can change the hotkey).
  3. Layout Fixer works out which layout the text was typed in, converts it key by key to the other layout, and pastes it back over the selection. Your previous clipboard text is restored.

Supported keyboard layouts

62 standard Windows layouts, including English (US), French AZERTY, German QWERTZ, Turkish Q/F, Arabic (101/102/AZERTY), Persian, Kurdish, Urdu, Hebrew, Syriac, Divehi, Russian, Ukrainian, Bulgarian, Kazakh and other Cyrillic layouts, Greek, Georgian, Armenian, Thai, Hindi and other Indic scripts, Khmer, Lao, Myanmar, Sinhala, Tibetan, and more. Convert between any two. Defaults come from the layouts installed in your Windows.

In the Microsoft Store the app is listed as “Layout Fixer – Arabic English” (Store ID 9N32C01ML8D1). Despite the name, it supports all the layouts below.

Features

  • One hotkey fixes the selected text in place, or optionally just the clipboard text
  • Automatic direction detection, or force one direction
  • Pick any pair of supported layouts; defaults come from your installed Windows layouts
  • Optionally switches your keyboard to the correct layout after fixing
  • Greek accents (tonos, dialytika) and Turkish characters are handled; digits are kept as typed
  • Runs in the system tray, optional start with Windows
  • Interface in 15 languages: Arabic, German, Greek, English, Spanish, Persian, French, Hebrew, Hindi, Kurdish (Sorani), Portuguese (Brazil), Russian, Thai, Turkish, Ukrainian — with right-to-left support
  • 100% offline: no internet access, no telemetry, no ads, no account

Limitations

  • Windows only (no macOS, Linux, Android or iOS version).
  • Chinese, Japanese and Korean IME input are not supported (direct keyboard layouts only).
  • Characters typed with AltGr are not mapped (for example Ukrainian ґ stays as is).
  • Some ligature keys (for example Arabic لا) cannot round-trip letter-for-letter.
  • It remaps keys, it does not translate: ghbdtn becomes привет, not “hello”.

Frequently asked questions

How do I fix text typed in the wrong keyboard layout on Windows?

Install Layout Fixer from the Microsoft Store, select the text that came out in the wrong layout and press Ctrl+Shift+L. The selection is replaced with the text converted to the correct layout. Windows itself has no built-in command for this; without a tool you have to delete and retype.

How do I convert “ghbdtn” to Russian?

“ghbdtn” is “привет” typed with the English (US) layout active instead of Russian. Select it and press Ctrl+Shift+L in Layout Fixer and it becomes “привет”. Whole sentences work too: “Ghbdtn? vbh” becomes “Привет, мир”.

I typed Arabic with English letters by mistake (like “hgsghl ugd;l”). How do I fix it?

That is Arabic typed while the English layout was active. Select it and press Ctrl+Shift+L: “hgsghl ugd;l” becomes “السلام عليكم” and “lvpfh” becomes “مرحبا”. It also works the other way, e.g. “اثممخ” becomes “hello”.

Can it convert the other way, from Cyrillic, Hebrew or Arabic gibberish back to English?

Yes. With automatic detection, “руддщ цщкдв” becomes “hello world”, “יקךךם” becomes “hello” and “ηελλο” becomes “hello”. You can also force one direction in Settings.

Which languages and keyboard layouts does Layout Fixer support?

62 standard Windows layouts across Arabic, Cyrillic, Thai, Indic, Greek, Hebrew, Georgian, Armenian, SE Asian scripts, French AZERTY, German QWERTZ and more — converted between any two. The app interface is available in 15 languages.

Is Layout Fixer a translator?

No. It converts each character to the one on the same physical key in the other layout, which is exactly what you would have typed with the right layout active. It does not translate meaning.

Does it work in Word, Chrome, Outlook or Telegram?

It works in most Windows apps where you can select text and use Ctrl+C / Ctrl+V, including browsers, Microsoft Office, email clients and desktop messengers. If an app blocks copy and paste, you can use the clipboard-only mode instead.

Does Layout Fixer switch the layout automatically as I type?

No. It never watches your typing. It only acts when you press the hotkey on selected text. After a fix it can optionally switch your active keyboard layout to the correct one.

Is my text sent anywhere?

No. Layout Fixer works fully offline, has no telemetry or analytics, and never saves the text it converts.

How much does it cost, and is there a Mac or mobile version?

It costs US$1.99 with a 7-day free trial in the Microsoft Store (prices vary by country). It is available only for Windows 10 (1809 or later) and Windows 11.
